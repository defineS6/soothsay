# Soothsay 设计语言

Soothsay 采用**现代清爽卡片界面（Modern Clean Card UI）**作为基线设计系统，并以统一的语义化 CSS 变量驱动八套外观主题（默认、纸墨、玄砚、青岚、暮霭、竹涧、沉香、琥珀）。

> 核心气质：干净利落、层次分明、信息密度合理；排盘数据可横向直观对比，长文解读居中舒适阅读。

---

## 1. 色彩与多主题 Token 体系

默认主题采用**纸墨配色**——温润宣纸基底（`#F3EDE2`）搭配暖白卡片表面（`#FCFAF5`）、深墨正文（`#1C1917`）与朱砂印记强调色（`#9F3A2F`）。所有组件均仅依赖语义 Token，不编写针对单一主题的结构覆写补丁。

| Token | 默认值 | 用途 |
|---|---|---|
| `--bg` | `#F3EDE2` | 页面主背景（宣纸暖底） |
| `--bg-soft` | `#E7DFD0` | 胶囊底色 / 次级填充 |
| `--surface` | `#FCFAF5` | 卡片主表面 |
| `--surface-raised` | `#F6F1E7` | 内嵌卡片 / 表头 / 输入框底色 |
| `--panel-bg` | `rgba(252, 250, 245, 0.94)` | 顶栏与主面板卡片背景 |
| `--ink` | `#1C1917` | 主文字与标题 |
| `--ink-soft` | `#44403C` | 正文与次级信息 |
| `--muted` | `#78716C` | 辅助说明与弱化标签 |
| `--line` | `#DCD3C2` | 标准 1px 卡片边框 |
| `--line-soft` | `#E9E2D4` | 面板内部分割线 |
| `--accent` | `#9F3A2F` | 选中态、日柱标记、焦点指示 |
| `--primary-bg` | `#9F3A2F` | 主操作按钮实底 |

扩展主题通过 `<html data-theme="...">` 切换对应变量：
- `ink`（纸墨）：宣纸暖米底 + 朱砂点睛
- `inkstone`（玄砚）：深邃暗黑底 + 哑光古铜
- `mist`（青岚）：冷雾青灰底 + 远山蓝
- `dusk`（暮霭）：柔雾暖藕底 + 暮紫点缀
- `bamboo`（竹涧）：浅苔宣纸底 + 苍竹点青
- `agarwood`（沉香）：乌木暖炭底 + 泥金点烛
- `amber`（琥珀）：善本麻纸底 + 岩茶温润

## 2. 字体与排版层级

- **UI 与正文（`--font-body`）**：`Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
  - 导航、面板标题、按钮、表单、解读正文统一使用现代无衬线字体，保证高清晰度与现代应用质感。
- **命盘干支展示（`--font-display`）**：`"Songti SC", "STSong", "Noto Serif SC", Georgia, serif`
  - 仅用于八字四柱天干地支核心大字与开场仪式符号，突出命盘核心辨识度。

## 3. 布局与响应式架构

1. **外壳与顶栏对齐（`.app-shell` & `.topbar`）**：
   - 顶栏与下方工作区共享 `--container-max: 1440px` 容器宽度，左右边界严格对齐，采用标准 Flex 纵向流，避免悬浮顶栏遮挡内容。
   - 顶栏按钮统一为 `38px` 等高控件，上下文选择器（大师、生辰）采用单行胶囊卡片呈现。
2. **桌面双栏工作台（`> 900px`）**：
   - 左栏排盘面板（`360px–416px`）：顶部大师信息条 → 四柱 4 列对比盘面 → 五行统计与日主摘要 → 手风琴折叠详情卡（命盘要素、五行旺衰、命局关系、大运流年） → 底部吸底操作栏。
   - 右栏解读对话面板（`1fr`）：顶部面板标题栏 → 中部宽敞滚动阅读区（正文与对话卡片统一居中限宽 `740px`，消除多层边框套娃） → 底部沉底追问输入栏。
3. **设置与后台面板**：
   - 设置页在桌面端采用响应式双栏卡片并排展示“凭据”与“WebDAV 同步”。
   - 生辰档案弹窗采用左列表 + 右紧凑 3 列网格表单，减少纵向滚动。
4. **平板与移动端工作流（`<= 900px`）**：
   - 统一启用四 Tab（首页 / 命盘 / 解读 / 我的）与底部悬浮导航栏，消除中等屏幕下双面板上下挤压的断层。
   - 移动端四柱盘面保持 4 列横向并排，确保年、月、日、时四柱可同屏直观对比。
